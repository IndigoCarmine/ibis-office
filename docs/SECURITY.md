# Reporting Security Issues

[English](#reporting-security-issues) | [日本語](#セキュリティの問題の報告日本語)

If you find a security issue (vulnerability) in Acauda Office, **do not post it in a public issue or pull request**. Report it privately with "Report a vulnerability" on this repository's [Security](https://github.com/IndigoCarmine/ibis-office/security) tab.

If the issue is in ibisOffice too (it happens in the official ibisOffice release), please also report it to ibis inc. as described in [ibisOffice's SECURITY.md](https://github.com/ibisjp/ibis-office/blob/main/docs/SECURITY.md).

Please include what the issue is and its possible impact, the steps to reproduce it (and the file that triggers it, with no personal or confidential information), and the Acauda Office version and your OS or browser.

# セキュリティの問題の報告（日本語）

Acauda Office にセキュリティの問題（脆弱性）を見つけたときは、**公開の Issue やプル リクエストに書かないでください。** このリポジトリの [Security](https://github.com/IndigoCarmine/ibis-office/security) タブの「Report a vulnerability」から、非公開で知らせてください。

公式の ibisOffice でも起きる問題であれば、[ibisOffice の SECURITY.md](https://github.com/ibisjp/ibis-office/blob/main/docs/SECURITY.md) の方法で、アイビスにも知らせてください。

問題の内容と影響、再現の手順（問題が起きるファイルがあれば、個人の情報や機密の情報を含まないもの）、Acauda Office のバージョン、OS またはブラウザを書いてください。
