# Contributing to Acauda Office / Acauda Office への貢献

**English** follows first; [日本語は下にあります](#日本語).

## English

Bug reports, requests and pull requests are welcome in [this repository](https://github.com/IndigoCarmine/ibis-office).

- **Problems with Acauda Office go here, not to ibis inc.** If you can show that a problem is in ibisOffice too (it happens in the official ibisOffice release), please also report it to [ibisOffice](https://github.com/ibisjp/ibis-office/issues).
- **Report security issues privately**, as described in [SECURITY.md](SECURITY.md), not in Issues.
- A bug report helps most with: the version (Help > About), the OS and its version, the steps, what you expected and what happened, and a file that shows it (only one you may make public).
- Code you contribute is licensed under AGPL-3.0-only, like the rest of Acauda Office. Keep the license lines at the top of each Rust source.

## 日本語

不具合の報告、要望、プル リクエストを、[このリポジトリ](https://github.com/IndigoCarmine/ibis-office) で受け付けます。

- **Acauda Office の不具合は、アイビスではなく、ここに報告してください。** 公式の ibisOffice でも起きる不具合であれば、[ibisOffice](https://github.com/ibisjp/ibis-office/issues) にも報告してください。
- **セキュリティの問題は Issues に書かず、**[SECURITY.md](SECURITY.md) の方法で知らせてください。
- 不具合の報告には、バージョン（ヘルプ > Acauda Office について）、OS とそのバージョン、手順、期待したことと起きたこと、再現するファイル（公開してよいものだけ）があると助かります。
- 貢献していただいたコードは、Acauda Office のほかの部分と同じく、AGPL-3.0-only で公開します。Rust のソースの先頭にあるライセンスの行は残してください。
