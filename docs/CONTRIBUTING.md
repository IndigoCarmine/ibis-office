# Contributing to ibisOffice / ibisOffice への貢献

**English** follows first; [日本語は下にあります](#日本語).

## English

Thank you. Bug reports, requests, investigations and proposed fixes are all welcome.

### How to send

- **Please use Issues.** We do not accept pull requests at the moment. For a proposed fix, paste the diff in the issue or link to a branch of your fork.
- **Report security issues privately through [SECURITY.md](SECURITY.md), not in Issues.**
- A bug report helps most with: the ibisOffice version (Help > About), the OS and its version, the steps, what you expected and what happened, and a file that shows it (only one you may make public; please do not attach files containing people's names or company information).

### One-line reply for an issue with code

ibisOffice is offered under both the AGPL and a commercial license, so we need your permission to take code you wrote as it is. On an issue with code (including a diff or a branch of your fork), please reply with one of these. See [CLA.md](CLA.md) for the details.

- **Use my code**
  ```
  I agree to the ibisOffice CLA.
  ```
  For a company:
  ```
  I agree to the ibisOffice CLA on behalf of <company name>.
  ```
- **Don't use my code; reimplement it**
  ```
  Please reimplement it.
  ```

Either way, we are grateful for the report and the idea.

### What happens next

- ibis reviews it and replies in the issue whether it will take the code, reimplement it, or not proceed.
- When we take your code or build on your idea, we may credit your GitHub account in the CHANGELOG or the issue.

## 日本語

ありがとうございます。不具合の報告、要望、原因の調べ、修正の案、どれも歓迎します。

### 送り方

- **Issues に書いてください。** 今はプル リクエストを受け付けていません。修正の案は、issue に差分を貼るか、フォークのブランチへのリンクを書いてください。
- **セキュリティの問題は Issues に書かず、[SECURITY.md](SECURITY.md) の窓口から知らせてください。**
- 不具合の報告には、次があると助かります：ibisOffice の版（ヘルプ ＞ バージョン情報）、OS とその版、手順、期待した結果と実際の結果、再現できるファイル（公開してよいものだけ。人の名前・会社の情報などが入ったファイルは添付しないでください）。

### コードを含む issue には、1 行の返信をお願いします

ibisOffice は AGPL と商用ライセンスの 2 つで配っているため、書いてくれたコードをそのまま取り込むには許可が要ります。コード（差分・フォークのブランチを含みます）を含む issue には、どちらか 1 行を返信してください。詳しくは [CLA-ja.md](CLA-ja.md) にあります。

- **取り込んでよい**
  ```
  I agree to the ibisOffice CLA.
  ```
  会社として出す場合：
  ```
  I agree to the ibisOffice CLA on behalf of <会社名>.
  ```
- **コードは使わず、アイビスが書き直してほしい**
  ```
  Please reimplement it.
  ```

日本語で「CLA に同意します」「アイビスで書き直してください」と書いてもらっても構いません。どちらを選んでも、報告やアイデアはありがたく使わせてもらいます。

### その後

- アイビスが内容を確かめ、取り込むか、書き直すか、見送るかを issue で知らせます。
- 取り込んだ場合や、アイデアをもとに書き直した場合は、CHANGELOG や issue で、報告してくれた方の GitHub のアカウントを紹介することがあります。
