# ibisOffice Contributor License Agreement (CLA)

## The short version

Thank you for your ideas, bug reports and fixes.

ibisOffice is offered under both the AGPL and a commercial license. ibisOffice has no business model built around it; we offer the commercial license only so that companies that modify the source but cannot publish their changes have a choice. So to take code you wrote (pasted in an issue, a diff, or a branch of your fork) as it is, we need your permission to ship it under the commercial license too. This CLA asks for that permission. You keep the copyright.

On an issue or a pull request with code, please reply with one of these:

- **Use my code** → comment:
  ```
  I agree to the ibisOffice CLA.
  ```
  For a company:
  ```
  I agree to the ibisOffice CLA on behalf of <company name>.
  ```
- **Don't use my code; reimplement it yourselves** → this is all we need:
  ```
  Please reimplement it.
  ```

Either way, we are grateful for the report and the idea.
