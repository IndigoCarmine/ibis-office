# Using the ibisOffice Name and Logo

[English](#using-the-ibisoffice-name-and-logo) | [日本語](#ibisoffice-の名前とロゴの使い方日本語)

The ibisOffice name and logo are trademarks of ibis inc. (registration of the logo is pending in Japan). The source code is available under AGPL-3.0 or a commercial license, but neither license grants any right to use the name or the logo. Please use them according to the rules on this page.

## Derivatives must display "Powered by ibisOffice" in the user interface (required)

When you distribute or provide a modified version of ibisOffice, or a product or service that includes ibisOffice (a "derivative"), you must display the following. This is an additional term under Section 7(b) of AGPL-3.0, requiring the preservation of author attributions.

- In the derivative's user interface (its "About" screen, or the equivalent place), display "Powered by ibisOffice" with a link to https://github.com/ibisjp/ibis-office.

## Requests outside the product

We kindly ask, but do not require, the following. These are requests, not conditions of either license.

- In the derivative's descriptions (website, store listing, README and so on), please also write "Powered by ibisOffice" or "Based on ibisOffice".
- On any page where the derivative's binaries (installers, apps, executables and so on) can be downloaded, please display "Powered by ibisOffice" with a link to https://github.com/ibisjp/ibis-office.

## What you may do freely

- State facts such as "Powered by ibisOffice", "Based on ibisOffice" or "compatible with ibisOffice"
- Use the ibisOffice name and logo as they are when redistributing ibisOffice as released by ibis inc., without modification
- Write about ibisOffice in articles, reviews, introductions and teaching materials

## What requires permission from ibis inc.

- Using "ibisOffice" as the name of a derivative (please give your derivative a different name)
- Using the ibisOffice logo, or a logo similar to it
- Describing a derivative in a way that suggests it is an official ibis inc. product, or is approved or sponsored by ibis inc.
- Using domain names, app names or account names that contain "ibisOffice"

For permission or commercial licensing: ibis inc. <https://ssl.ibis.ne.jp/support/Entry?svid=30>

# ibisOffice の名前とロゴの使い方（日本語）

「ibisOffice」の名前とロゴは、株式会社アイビスの商標です（ロゴは日本で商標登録を出願中）。ソースコードは AGPL-3.0 または商用ライセンスで利用できますが、どちらのライセンスも、名前とロゴを使う権利までは与えていません。名前とロゴは、このページの決まりに従って使ってください。

## 派生物の画面には「Powered by ibisOffice」と表示しなければなりません（必須）

ibisOffice を改変したもの、または ibisOffice を組み込んだ製品・サービス（以下「派生物」）を配布・提供するときは、次の表示をしなければなりません。これは AGPL-3.0 第 7 条(b) に基づく、作者の表示を保つ追加の条件です。

- 派生物の画面（「このアプリについて」の画面、またはそれに当たる場所）に「Powered by ibisOffice」と表示し、https://github.com/ibisjp/ibis-office へのリンクを付けなければなりません。

## 製品の外でのお願い

次のことをお願いします。必須ではありません。どちらのライセンスの条件でもない、お願いです。

- 派生物の説明（Web サイト、ストアの説明、README など）にも、できれば「Powered by ibisOffice」または「Based on ibisOffice」と書いてください。
- 派生物のバイナリ（インストーラー・アプリ・実行ファイルなど）をダウンロードできるページにも、できれば「Powered by ibisOffice」と表示し、https://github.com/ibisjp/ibis-office へのリンクを付けてください。

## 自由にしてよいこと

- 「Powered by ibisOffice」「Based on ibisOffice」「ibisOffice をもとにした」「ibisOffice と互換」と、事実のとおりに書くこと
- アイビスが配布した ibisOffice を、改変せずにそのまま再配布するときに、「ibisOffice」の名前とロゴをそのまま使うこと
- 記事・書評・紹介・教材で、ibisOffice について書くこと

## アイビスの許可が要ること

- 派生物の名前として「ibisOffice」を使うこと（派生物には別の名前を付けてください）
- ibisOffice のロゴや、それに似たロゴを使うこと
- 派生物が、アイビスの公式の製品である、またはアイビスが承認・後援していると受け取られる書き方をすること
- 「ibisOffice」を含むドメイン名・アプリ名・アカウント名を使うこと
